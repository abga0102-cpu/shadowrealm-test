# V494 · Accomplissements de niveau personnage

V494 replaces the abandoned V492 implementation with an architecture-safe integration inside the existing accomplishment claim authority.

Free Minerai milestones: 10=250, 15=350, 20=500, 25=700, 30=1000, 35=1200, 40=1500, 50=2000, 60=2500, 70=3000, 80=3500, 90=4000, 100=5000.

Premium grants a separate 25% Minerai bonus for each completed milestone. Existing `accomplishments.claimed` and `accomplishments.premiumClaimed` save maps are reused, so no save migration is required.
